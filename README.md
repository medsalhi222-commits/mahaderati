# محاضراتي — DROUSSI Université v1.0

تطبيق مستقل للطالب الجامعي. لا يحتوي على نظام ولي أو صلاحيات أطفال.

## النسخة الأولى: «محاضراتي»
- إضافة المواد الجامعية.
- إضافة المحاضرات لكل مادة.
- بيانات المحاضرة: العنوان، التاريخ، الأستاذ، القاعة.
- تصوير صفحات/سبورة المحاضرة أو إضافتها من الهاتف.
- حفظ الصور داخل تخزين التطبيق.
- استخراج النص OCR بالعربية والفرنسية والإنجليزية.
- ملاحظات وملخص لكل محاضرة.
- البحث في المواد والمحاضرات.
- تصدير المحاضرة إلى PDF مع الصور والنص المستخرج والملاحظات.
- تخزين محلي على الهاتف.

## قرار التصميم
هذا المشروع مستقل عن DROUSSI المدرسي. لا توجد فيه علاقة ولي/تلميذ.

## ملاحظة البناء
بيئة العمل التي أُنشئت فيها هذه النسخة لا تحتوي على Flutter SDK، لذلك لم يتم الادعاء بإجراء `flutter build apk` هنا. المشروع يحتوي على مصدر Flutter وpubspec ويمكن بناؤه في بيئة Flutter.
